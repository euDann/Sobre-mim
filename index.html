Como eu trabalho

1. Entender a venda

Antes do layout: quem clica, o que precisa fazer (WhatsApp, plano, orçamento) e o que gera desconfiança.

2. Estrutura antes de efeito

Hierarquia, contraste, um CTA principal. Animação só depois que a página já converte sem JavaScript.

3. Código simples de manter

CSS com variáveis, seções claras, nada de framework só para parecer sênior. Git público quando faz sentido.

4. Medir o básico

Título, descrição, preview no WhatsApp, velocidade e clique no botão certo. SEO honesto, sem promete “topo do Google”.
